# Добро пожаловать

В данном проекте действие игры разворачивается в мире, в котором весь технологический прогресс основан на паровой энергии.

Цель проекта — подняться по карьерной лестнице в необычной городской среде.

## Основные задачи:
- моделирование потока людей
- анализ реакции на рекламу
- разработка алгоритмов взаимодействия
